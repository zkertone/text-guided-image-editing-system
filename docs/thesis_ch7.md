# 第7章 总结与展望

## 7.1 本文工作总结

本文围绕《基于大模型的文字驱动图像编辑方法与系统实现》这一课题，基于预训练扩散模型完成了一个文字驱动图像编辑系统原型的设计与实现。课题工作以工程实现为主线，不涉及从零训练大模型，也不以提出新的扩散模型理论为目标，而是重点围绕预训练模型调用、系统功能集成、交互界面构建、实验记录与案例分析等内容展开。

在系统设计方面，本文对系统总体组成、核心模块、运行流程、功能模块和文件组织方式进行了分析与说明，明确了模型加载、图像编辑、界面交互和实验记录等部分在系统中的作用关系。在系统实现方面，本文基于 Hugging Face Diffusers、PyTorch 和 Gradio 等技术，完成了整体编辑、局部编辑和结构保持编辑三种模式的集成实现，并建立了输入输出图像自动保存、实验信息摘要展示和 CSV 实验日志记录等配套机制。

在实验与测试方面，本文通过功能测试与典型案例分析相结合的方式，对系统原型的实际运行效果进行了验证。实验结果表明，系统能够完成整体编辑、局部编辑和结构保持编辑等基本任务，并在颜色变化、局部区域修改和结构保持风格化等场景下生成具有一定可解释性的结果。同时，通过对问题案例的分析，本文也总结了系统在提示词敏感性、整体编辑精细控制能力、局部编辑复杂纹理处理能力以及结构保持编辑适用范围等方面存在的不足。

总体来看，本文完成了一个基于预训练模型的文字驱动图像编辑原型系统，实现了从系统设计、功能集成到实验验证和问题分析的完整流程，较好地达到了工程实现型本科毕业设计的基本要求。

## 7.2 课题完成情况总结

结合任务要求与当前项目实际完成情况，本文已完成以下几个方面的工作。

首先，完成了文字驱动图像编辑系统原型的整体设计与实现。系统围绕图像输入、文本提示词输入、编辑模式选择、结果输出和实验记录等流程展开，形成了较为清晰的工程结构。其次，完成了三种主要编辑模式的集成实现。系统支持基于 InstructPix2Pix 的整体编辑、基于 Stable Diffusion Inpainting 的局部编辑，以及基于 Canny ControlNet 的结构保持编辑，不同模式分别对应不同应用场景，使系统具备了较为丰富的图像编辑能力。

此外，系统还完成了基础交互界面的搭建。系统基于 Gradio 构建了可视化操作界面，支持原图上传、Prompt 输入、Mask 指定、参数设置、结果展示和实验摘要输出等功能，能够满足系统演示和实验操作需要。在实验记录与结果管理方面，系统能够自动保存输入图像、输出图像和必要的控制图，并将实验参数与结果路径记录到 CSV 文件中。同时，通过版本记录和案例索引等方式，对项目过程与实验结果进行了整理，为后续论文撰写提供了支持。

在系统测试方面，本文结合整体编辑正向案例、整体编辑问题案例、局部编辑案例和结构保持编辑案例，对系统当前效果进行了验证和讨论，能够较客观地反映系统的实际表现和存在问题。从整体完成情况来看，课题已经较完整地实现了“基于预训练模型完成文字驱动图像编辑系统设计与实现”的主要目标。

## 7.3 存在的不足

尽管本课题已完成系统原型的设计、实现与测试，但从实验结果和案例分析来看，当前系统仍存在一定不足。

首先，系统对提示词具有较强敏感性，不同提示词表达方式可能导致生成结果出现明显差异，因此结果稳定性仍有待提高。对于文字驱动图像编辑任务而言，提示词质量会直接影响模型输出，这使得系统在部分场景下较依赖用户的提示词设计经验。

其次，整体编辑模式虽然使用方便，但在处理局部目标明确的任务时，容易对非目标区域产生附带影响，因此在精细控制方面存在局限。对于需要仅修改图像中某一特定对象或局部属性的任务，整体编辑并不总能给出理想结果。

再次，局部编辑模式虽然能够通过 Mask 指定编辑范围，但在复杂纹理区域或细小边缘附近，结果仍可能出现边界不自然、细节失真或语义变化不够稳定等问题。这说明局部编辑功能在工程上已实现可用，但编辑质量仍受到模型本身能力的影响。

此外，结构保持编辑模式更适合风格化变化和结构约束场景，而不一定适合精细属性微调任务。换言之，该模式具有较明确的适用范围，其优势主要体现在保持原始轮廓和空间关系方面，而不是在所有图像编辑任务中都具有最佳表现。

最后，系统整体仍属于基于预训练模型的原型系统，实验结果在较大程度上受基础模型能力限制。本文重点在于系统集成与工程实现，而非底层模型性能优化，因此当前系统距离更高精度、更强稳定性和更高可控性的实际应用目标仍有一定差距。

## 7.4 后续展望

在当前工作基础上，后续可从系统完善和方法优化两个层面继续展开。

在系统完善方面，可进一步优化交互界面设计，使不同编辑模式下的操作流程更加清晰，并对实验结果展示、案例分类和参数记录方式进行进一步整理，以提高系统的使用便利性和实验管理效率。同时，也可以继续丰富案例库，积累更多不同场景下的成功案例与问题案例，为后续分析和展示提供更充分的支撑材料。

在方法优化方面，后续可进一步探索更适合特定任务场景的预训练模型，并结合实际编辑需求优化提示词设计策略，以提高系统在不同图像编辑任务中的稳定性和可控性。此外，对于局部编辑和结构保持编辑，也可继续探索更细致的区域约束或结构约束方式，以提升复杂场景下的编辑质量。

需要说明的是，上述展望主要属于后续可进一步研究和完善的方向。当前课题的重点仍在于基于预训练模型完成文字驱动图像编辑系统原型的设计、实现与验证。总体而言，本文的工作为后续在图像编辑系统集成、多模式交互设计和实验组织方面的进一步探索打下了基础。
