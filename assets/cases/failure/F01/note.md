# F01

## 基本信息
- 编辑模式：整体编辑
- Mask来源：不适用
- 输入图像：input.png
- 输出图像：output.png

## Prompt
Turn the orange into an apple

## 参数
- 推理步数：20
- 图像引导强度：2.5
- 文本引导强度：7.5

## 效果说明
- 结果未能较好地符合预期。
- 原始目标是将单个橙子替换为苹果，但输出结果中出现了多个苹果，且原有构图发生明显变化。
- 说明整体编辑模型在执行目标物体类别替换时，容易出现语义扩散和场景结构偏移问题。

## 简短结论
- 该案例不适合作为正向展示案例，但适合作为整体编辑局限性分析案例，用于说明目标物体替换任务中可能出现的结构失真问题。
