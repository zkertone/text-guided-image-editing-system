# C01

## 基本信息
- 编辑模式：结构保持编辑
- Mask来源：不适用
- 控制方式：Canny
- 输入图像：input.png
- 控制图像：canny.png
- 输出图像：output.png

## Prompt
cyberpunk light

## 参数
- 推理步数：20
- 图像引导强度：该模式未使用
- 文本引导强度：7.5

## 效果说明
- 系统成功从原图中提取出 Canny 边缘图，并在此基础上完成了结构保持编辑。
- 输出结果较好地保留了吊灯的主要轮廓和悬挂结构，同时根据文本提示生成了更明显的赛博朋克风格效果。
- 相比原图，结果图中的背景和材质细节变化较大，说明该模式更适合“结构约束下的风格变化”，而不是严格意义上的轻量属性编辑。

## 简短结论
- 该案例适合作为 Canny ControlNet 成功案例，用于展示系统新增的结构保持编辑能力。
